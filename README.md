# Word Counter

A simple Node.js command-line tool that counts the lines, words, and characters in a text file.

## Features

- Counts the number of **lines**
- Counts the number of **words**
- Counts the number of **characters**
- Simple and easy to use from the terminal

## Requirements

- [Node.js](https://nodejs.org/) (version 14 or newer)

## Installation

1. Clone or download this project
2. Open the project folder in your terminal:

```bash
   cd word-counter
```

## Usage

Run the program with the name of the text file you want to analyze:

```bash
node index.js sample.txt
```

Or use npm:

```bash
npm start sample.txt
```

## Example Output

```
File: sample.txt
Lines: 7
Words: 33
Characters: 215
```
